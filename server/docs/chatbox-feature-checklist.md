# Chatbox 客户端功能清单 — 可直接抄用的设计细节

日期:2026-08-03
来源:https://github.com/chatboxai/chatbox(main 分支,41k stars,Electron + React + Zustand + SQLite)

## 定位差异(我们的独有之处)

| 维度 | Chatbox | PicoAide-Next |
|---|---|---|
| 模型接入 | 用户自带 API key/Provider 配置 | **服务端网关**,员工登录即用,零配置 |
| Skill | 本地安装/发现(builtin + GitHub) | **服务端商城**,管理员上架,建议清单下发 |
| MCP | 用户手动配置(stdio/SSE) | 服务端下发默认 MCP + 凭证 |
| 数据 | 本地 SQLite | 本地 SQLite(会话/记忆)+ 服务端(计量/权限) |
| 工作模式 | 纯聊天客户端 | 聊天 + **本地 Agent 引擎**(文件/终端/浏览器/屏幕/审批) |
| 目标 | 个人 LLM 客户端 | 企业内网办公智能体 |

标注说明:**[抄]** = 设计细节直接拿来用;**[适配]** = 借鉴但需结合服务端/Agent 改造;**[不做]** = 不适用。

| 1.8 | 流式文本渐显 | `StreamingTextFade`:流式增量逐字淡入(非瞬时跳变) | [抄] 小细节,视觉加分 |
