### A3 用量(17 项:高 3 / 中 5 / 低 9)
- **高1** 总费用卡环比实为 token 环比(`Usage.tsx:120-135` 只累加 prompt+completion),金额无自己环比
- **高2** 「总 tokens」卡 desc 写"不含 embedding"但数值实际含 embedding(`usage.go:337-340` 未排除),与「输入 tokens 含 embedding」矛盾
- **高3** usage 表无 `created_at` 单列索引(`0004_usage.sql` 仅 user+time 复合),日期范围聚合全表扫描;60s 轮询 = 每分钟全表聚合
- 中:CSV 忽略过滤/无转义与公式注入防护;接口无界(from/to 可缺省、group=user 无上限、无 to<from 校验);配额面板只看前 200 用户;统计含 admin 而配额豁免 admin 无法对账

### A4 知识库+审计(23 项:高 3 / 中 9 / 低 11)
- **高1** import-status 契约缺 processing 状态 + 单文件上传后前端不轮询 → 导入进度永久卡"待处理"
- **高2** 原始文件缺失的 pending 文档让队列 claim→release 死循环,队头阻塞整条队列瘫痪
- **高3** 编辑 pending/error 文档会被异步提取覆盖(真实数据丢失);error 文档编辑后状态不恢复
- 中:审计页 ACTION_LABEL 与服务端动作集漂移(缺 8 项);技能下架无审计;search 无 folder_id 过滤;updateDoc 无状态守卫;setEmbeddingModel 不校验模型存在性
- 低:11 项(格式/空态/确认等)

### A5 商城+公共层(22 项:高 2 / 中 9 / 低 11)
