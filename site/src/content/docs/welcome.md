欢迎来到 PicoAide Harness Wiki！

PicoAide Harness 是**企业级 DeepSeek Harness 一体化平台**：桌面客户端 + 本地智能体引擎 + 管理后台，开箱即用，一切皆插件，数据留在本机。

| 组成 | 职责 |
|---|---|
| **桌面客户端** | 原生窗口、对话、能力中心、连接器、定时任务、浏览器、记忆——员工每天的入口 |
| **本地智能体引擎** | 自动启动/停止/恢复官方 DeepSeek Harness 服务（固定版本原样运行），数据留在本机 |
| **企业服务端 + 管理后台** | 账号（local/LDAP/OIDC）、模型网关、限流、计量计费、部门预算、市场与共享审批、审计 |
