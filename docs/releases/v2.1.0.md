# PicoAide Harness v2.1.0

发布于 2026-08-23。本版本是产品从桌面骨架走向完整产品形态的大版本：桌面客户端升级源切换至 GitHub Releases，实现三平台打包与自动化发布；插件生态体系成型（定时任务 / 任务看板 / 内嵌浏览器 / 五轨记忆 / 连接器中心 / 社区市场）；服务端 Go 网关与管理后台上线；并完成大规模安全加固。

## 发布与分发

- **升级源切换至 GitHub Releases**：桌面客户端自动升级检查改从 GitHub Releases 获取最新版本，安装包按资产名匹配下载并附带 SHA-256 完整性校验，链路透明可审计
- **三平台自动打包**：macOS universal DMG、Windows NSIS Setup / Portable ZIP、Linux AppImage + deb；推送版本 tag 由 CI 自动构建并发布（含 SHA256SUMS.txt 清单）
- macOS universal 打包豁免 CLI 二进制目录、smoke 验证器从 package.json 读取真实产品名、签名与产物门槛
- 修复 Windows 打包构建顺序与安装包缺失企业插件产物导致的加载失败

## 桌面客户端

- 产品名与品牌全面切换为「PicoAide Harness」（包名 / logo / 首屏 / 窗口标题），品牌 mark 按 1.25× 放大版 tray 图标对齐，登录页跟随系统主题
- 主窗口登录门禁（企业登录网关插件、原生登录窗口，登录页 / 设置页品牌化）
- 固定 desktop profile 与高级模式，移除终端 / 模式切换 / profile 切换；产品数据目录统一为 `~/.picoaide-harness`
- 全部编译产物进入 asar 虚拟文件系统（仅原生二进制物理解包），修复打包沙箱内子进程 spawn 与 asar 链接读取
- 桌面日志系统：分日轮换文件日志、logLevel 设置、密钥脱敏；诊断导出（崩溃证据、主线程外执行、隐私确认）
- 升级确认门控、结构化 issue forms、Windows 工作区选择器与稳定本地 Web 端口

## 插件生态

- **dsh-cron 定时任务**（Host 权威账本 / cron 调度器 / 执行器 / 模型工具 / 定时中心 UI）
- **dsh-task 任务看板**（任务账本 / 真实会话执行 runner / 上下文注入 / 模型工具 / 五列看板 UI）
- **dsh-browser 内嵌浏览器**（独立窗口 + AI 控制遮罩 + 接管挂起 agent loop）
- **dsh-memory-evolve 五轨记忆**、**dsh-account-card 账户卡**（实时网关余额）、**dsh-better-sidebar** 侧边栏
- **community marketplace**（只读社区目录 + 全索引包管理 + 引导动作 + 标准包源浏览）
- 上游 DeepSeek Harness 固定 pin 0.1.0-rc.8（rc.7 → rc.8 全程适配）

## 连接器

- 连接器框架与连接器中心（侧边栏独立入口、卡片网格设计），内置销售易 NeoCRM
- WorkBuddy 官方市场 98 个连接器全量接入；钉钉连接器（WorkBuddy CLI 设备流授权 + 官方 MCP）
- OAuth 按规范实现（RFC 9728 + RFC 8414）：state 校验与 60s 超时、回环回调加固、Bearer 注入与 token 刷新
- 斜杠命令（/connector 系列，只展示已连接连接器）；CLI 按需下载（dws / beisen-cli 开箱即用）
- 凭证安全加固（0600/0700 权限、原子写、防符号链接、id 白名单、64KB 读上限）；本地回环 API 信任围栏

## 服务端与安全

- 引入 Go 服务端（AI 网关代理、用量计量、Skill 商城）与 webadmin 管理后台、多平台 CI 产物矩阵
- 认证配置（LDAP / OIDC）与登录审计
- 多用户登录会话隔离（connectors / browser / cron / task / account-card）；证书 TOFU 未知指纹拒绝
- 安全与合规修复：Go 日志注入、许可证合规、越权 / 数据丢失 / 多版本断链 / 部署安全等审计项
- 客户端 E2E 自动化工具（e2e:client）与覆盖矩阵入仓库
