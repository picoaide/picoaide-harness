## 服务端：API 命名空间与 RBAC

- **API 命名空间拆分**：`/api/server`（管理 / 管理面）+ `/api/client/v2`（客户端 / 员工面）；webadmin、desktop client 与测试路由前缀全面统一（修复旧前缀 404 与 rbac fall-open 测试漏检）
- **RBAC 角色模型**：权限中间件与路由表；role-aware 导航；本地 only 的 admin 登录；auditor 登录拒绝并给出清晰提示
- **审计增强**：防篡改哈希链、登录事件、CSV 导出；OIDC 回调限流 + 登录成功 / 失败审计
- SSRF 防护：test-connection issuer 仅允许 https / loopback

## 品牌与门户（v3b）
