# v2.8.3-beta.3（2026-10-19）

> 一句话：升级到 DeepSeek Harness 0.2.1-rc.2，自动化任务改用官方 Schedule，
> 9 个官方实验性能力默认装配，并清理官方重复入口；这是一个用于实机验证的 beta。

| 项目 | 说明 |
| --- | --- |
| 版本类型 | 预发布（beta） |
| 升级建议 | 建议测试升级（预发布，不进入正式更新通道） |
| 影响面 | 桌面客户端（Linux / Windows / macOS）、服务端镜像内的客户端分发 |
| 产品代码变化 | 有（相对 v2.8.3-beta.2） |

## 一、DeepSeek Harness 升级到 0.2.1-rc.2

- **升级内容**：上游从 0.2.0-rc.2 升到 0.2.1-rc.2，包含新的客户端界面、会话标题、
  工具授权审查、持久终端等能力；同时删除上游运行时不变量服务（`invariants`），
  本仓 8 个自研包已同步移除 `./invariant` 伴生入口。
- **兼容处理**：MCP SDK 仍钉在 2.0.0（2.2.0 会覆盖声明 header）；本轮补丁、打包清单与
  许可文件已按新版本重新核对。
- **验证**：完整门禁、桌面 E2E、打包 asar 与 14 个 Yarn 补丁逐项校验均通过。

## 二、自动化任务改用官方 Schedule

- **变化**：自研 cron 已退役，侧栏「更多 → 自动化任务」现在打开官方 Schedule 任务中心，
  入口位置不变（浮层第一项）。
- **能力口径**：官方 Schedule 是“到点把提示词投递回原会话”的提醒，不再提供自研 cron 的
  工作区 / 智能体预设 / 权限钉住与独立执行结果；支持单次、间隔、每日、每周与 5 段 cron。
- **账号隔离**：任务目录、历史、更新、删除与到点投递都按当前登录账号过滤；签退或账号未恢复
  时不投递、不可见。
- **旧数据**：旧 cron 账本仍在数据目录只读保留，**不会自动导入**官方 Schedule；
  需要继续运行的任务请在官方「自动化任务」页重建。

## 三、默认启用的官方实验性能力

默认装配：语音输入、智能体团队、自动授权审查、思考过程机器翻译、持久终端、会话搜索、
随对话更新的标题、Ralph 循环、DSH 徽章技能。

- **智能体团队**：默认 preset 的 legacy `subagent` 工具已禁用，由 Agent Teams 的
  `send_message` / `list_agents` / `interrupt_agent` 接管。
- **自动授权审查**：Auto 权限预设下每次工具调用会多一次 LLM 复核，延迟与 token 成本会上升。
- **思考过程机器翻译**：默认 provider 为 Bing；展开思考过程时，该段文本会发送到
  `edge.microsoft.com`。本版设置页没有独立关闭项，涉及敏感内容时请不要展开思考过程。
- **持久终端 / 会话搜索 / Ralph**：终端会保留常驻 shell；会话搜索使用内存索引；
  Ralph 每轮启动新的子代理。

## 四、界面清理

- 隐藏官方侧栏重复入口：「插件」「自动化任务」行。
- 隐藏官方账户菜单中的「登录 / 退出登录 / 意见反馈」（保留「设置」）；macOS 与 Windows
  的中英文快捷键后缀均已覆盖。
- 设置窗口隐藏「模型」「内置插件」入口。
- 徽章技能改为当前产品/OEM 名，不再出现上游 dsh/DeepSeek 品牌、上游链接或上游徽章 PNG。

## 已知限制（本版认账）

- **旧 cron 任务不迁移**：升级后旧任务不会出现在官方「自动化任务」里，需要手工重建。
- **思考过程翻译默认出网**：见上节；本版没有可达的关闭入口，敏感会话请勿展开思考过程。
- **官方实验性能力**：以上 9 项随上游 experimental 包提供，默认值可能随上游升级变化。
- **任务只在应用运行时投递**：应用完全退出期间不触发；下次启动后当前账号的到期任务会补触发。
- **账号切换语义**：签退后不投递、不显示；换号登录后只看到新账号自己的任务。

- **迁移清单（机器可读锚点，供 `scripts/check-release-notes-migrations.mjs` 与 `git diff` 对拍）**：无

## 升级与回滚

- 服务端：取本版镜像附件，按 `docs/deploy/AI-DEPLOY.md` 升级；升级前必须备份，
  不要使用 `latest`，不要 `down -v`。
- 客户端：随服务端镜像分发，员工从自己登录的服务器取包。
- **回滚**：本版无数据库迁移，保留上一版镜像 tag，切回即可；客户端重新安装上一版包。
