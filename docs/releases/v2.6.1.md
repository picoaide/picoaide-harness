# PicoAide Harness v2.6.1（2026-09）

本版本补齐企业身份安全的一块空白：**密码全生命周期管理与管理员双因素认证（MFA）**。此前管理员无法修改自己的密码、也无法在界面上重置员工密码；员工本地账号没有任何自助改密入口；管理后台登录只有"用户名+密码"一道门。本版本一次补齐，并引入"管理员重置密码 → 用户下次登录强制改密"的闭环，以及可选的 TOTP 两步验证保护管理后台。

---

## 一、新增能力

### 1. 管理员修改自己的密码 🔐

侧边栏底部用户区新增「修改密码」入口（任意管理角色可用，文末支持 auditor）：输入当前密码 + 新密码（≥10 位）。**改密后该用户全部已登录会话（本会话与所有其他设备）立即全部吊销**，需要用新密码重新登录——防止旧令牌悬留。

### 2. 管理员重置员工/用户密码 + 强制改密 🔐

用户管理列表新增「重置密码」按钮（外部认证用户 LDAP/OIDC 密码由企业 IdP 管理，按钮禁用）；重置后：

- 该用户全部 API 令牌与登录会话立即吊销；
- 下次登录**必须先修改密码**（强制改密拦截页/对话框不可跳过；改密完成前服务端仅放行改密本身，其余业务接口一律 `403 PASSWORD_CHANGE_REQUIRED`）；
- 用户列表新增「上次改密」列（含初始密码标记）。

### 3. 员工（本地账号）自助修改密码 🔐

客户端「设置 → 账号」页新增内联修改密码表单（当前密码 + 新密码 ×2）。仅本地认证账号显示；企业统一认证（SSO/LDAP）用户显示"密码由企业 IdP 管理"提示。改密成功后所有会话吊销，客户端回到登录页。

### 4. 管理员 MFA（TOTP 双因素认证）🛡️

管理后台登录保护升级为可选两步验证（仅保护 webadmin 登录；员工客户端登录不受影响）：

- **开启**：安全设置 → 主密码确认 → 展示**二维码 + 密钥文本**（双显示）→ 录入验证器动态码即完成；
- **登录**：用户名密码通过后进入第二步动态码输入（挑战 5 分钟有效、失败 ≥5 次作废、一次性消费防重放，延续原有双桶限流）；
- **关闭**：主密码 + 当前动态码双验（防会话被劫持后自行关闭）；开启/关闭都会踢掉该管理员其他已登录会话；
- **兜底**（无恢复码方案）：其他超级管理员可在用户列表一键「重置 MFA」（关闭密钥并吊销其全部会话，不能对自己操作）；运维 CLI `picoaide-server --reset-mfa <username>` 可在唯一超管丢失验证器时紧急恢复（清密钥 + 吊销会话 + 审计留痕）。

### 5. 安全审计

新增审计动作：`password_change`（员工自助/强制改密）、`admin_password_change`、`password_force_change` 语义并入重置记录、`admin_mfa_enable` / `admin_mfa_disable` / `admin_mfa_reset`（管理端与 CLI）、`admin_mfa_login`（含失败计数），全部进入审计哈希链。

## 二、数据与接口变更

- **数据库迁移 `0057`**（自动执行，升级前请备份）：`users` 表新增 `password_must_change`、`password_changed_at`、`totp_secret`（AES-GCM 加密，绝不返回明文）、`totp_enabled`；新建 `admin_mfa_challenges` 一次性挑战表。
- **新端点**：

| 端点 | 说明 |
|---|---|
| `POST /api/client/v2/auth/password` | 员工自助改密（Bearer） |
| `POST /api/server/admin/me/password` | 管理员改自己密码 |
| `GET/POST /api/server/admin/me/mfa`（enable/verify/disable） | MFA 自助管理 |
| `POST /api/server/admin/login/mfa` | 两步登录第二步 |
| `PUT /api/server/admin/users/:id/mfa` | 管理员重置他人 MFA |
| `GET /api/server/admin/me/mfa` | 查询 MFA 状态 |

- 登录响应新增 `must_change_password`；用户对象新增 `source` / `password_changeable` / `password_must_change` / `mfa_enabled` 字段（客户端与 webadmin 据此渲染入口）。
- **运维 CLI**：`picoaide-server -data <dir> -pg-dsn <dsn> --reset-mfa <username>`（操作模式，不启动服务；写入审计 `admin_mfa_reset(cli)`）。详见 `docs/02-build-deploy.md`。

## 四、升级注意

1. **迁移 `0057` 自动执行**；服务端与 webadmin 同步升级（接口契约变更）。
2. **被重置过密码的用户下次登录会进入强制改密流程**，请提前告知（临时密码将不被视为长期凭据）。
3. MFA 为可选功能：开启只影响自己的 webadmin 登录；**建议在部署完成前先让一名管理员开启并验证两步登录流程**，再通知其他管理员。
4. 忘记 MFA 验证器的恢复路径：另一超级管理员「重置 MFA」或运维 CLI `--reset-mfa`（生产部署文档已含说明）。
