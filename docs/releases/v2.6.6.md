# PicoAide Harness v2.6.6（2026-09）

本版本核心是 **macOS 分发链路正式签名 + 公证**：mac 安装包从"未签名冒烟"升级为"开发者 ID 签名 + Apple 公证"，用户下载后**双击即可直接打开**，不再被 Gatekeeper 拦截。

---

## 一、macOS 签名与公证 ⭐

- **Developer ID Application 签名**：universal DMG（Intel + Apple Silicon）由 CI 在 tag 推送时自动完成代码签名，签名身份为 `Developer ID Application: xinlei shi (78W9HZYR6Q)`（证书有效期至 2031-09-05）；
- **Apple 公证（notarize）**：签名后自动提交 Apple 公证服务扫描并回钉公证票据（`stapler`），Gatekeeper 放行；
- **发布后自动校验**：挂载 DMG 后执行 `codesign --verify --deep --strict`、`spctl --assess`、`stapler validate` 与双架构（x86_64/arm64）检查，任一项失败则不产出 Release；
- **密钥纪律**：签名/公证凭据只保存在 GitHub Actions Secrets（libsodium 加密），仅注入 electron-builder 子进程；缺失任一凭据时预检直接失败（fail-loud），**绝不会发布未签名/未公证的 DMG**；
- 未签名冒烟包（`dist:mac-smoke`）仍在 PR/分支 CI 上运行作为打包回归门禁，tag 发布不再重复构建（节省 macOS runner 计费）。

## 二、CI 与构建修复

- Desktop 安装包进一步瘦身 + CI 提速（缓存升级 actions/cache v4 → v6、e2e 登录与品牌标题修复）；
- Docker 构建注入仓库根 `brands/` 命名上下文，修复 buildx 命名上下文与 build-push-action v7 输入名（`build-contexts`）兼容问题；
- 跨工作区与 server 死代码清理。

## 三、升级提示

- macOS 用户：升级后安装包为签名+公证版本，双击打开即可，无需"右键打开"或系统设置放行；
- Windows / Linux 安装包暂未签名（沿用 v2.6.5 状态），下载后请核对 `SHA256SUMS.txt`；
- 服务端通过 Docker 镜像 `ghcr.io/picoaide/picoaide-harness-server:v2.6.6` 自动发布，schema 迁移自动执行。
