发布于 2026-08-26。本版本完成产品形态收敛：能力分发统一为「技能商店 + MCP 连接器」两种标准形态，能力中心市场 / 组织合并，早期 CLI 工具化方案整体移除。

## 能力中心归一：市场 / 组织合并

- 市场与组织合并为单一「市场」来源：服务端 `source=market` 合并返回，**跨源同名冲突强制阻断（409）**
- 客户端技能中心 UI 缺陷修复（来源切换 / 搜索 / 跨源归并）
- 连接器 dws 凭证落盘统一指向产品 DSH HOME

## CLI 工具化整体移除：技能 + MCP 双标准形态

- 早期「CLI 即 skill」方案（自动安装 dws / wecom-cli / lark-cli / beisen-cli 等命令行工具）**整体移除**——CLI 直接 spawn 存在跨平台分发、安全与运维复杂度问题
- **最终架构定案**：厂商 CLI 能力改由技能商店以 SKILL.md 分发（上传 → 审批 → 授权 → 员工安装），模型读 skill 按引导操作；MCP 能力统一走连接器框架
- 连接器同步收敛为**纯 MCP 连接器**：删除 urlCommand 与 CLI 连接器，只保留 OAuth / streamable-http 形态（内置销售易 NeoCRM 与 Moka HR 智能体）
