发布于 2026-09-01。v2.5.6 发布后收到两个用户反馈并修复：技能卡片看不到详细介绍、安装技能报 `unsafe path in archive: ./`。

## 修复

- **技能卡片描述可展开全文**：能力中心技能/智能体卡片不再把描述硬截断为 3 行——点击描述区域展开全部内容（再点收起），鼠标悬浮可看全文；描述很长的卡片高度自动适应
- **安装 zip 兼容 `./` 根目录条目**：`zip -r skill.zip .` 这类常见打包产物的 zip 含 `./` 根目录条目，此前被安装器误判为不安全路径拒绝（报 `unsafe path in archive: ./`）。现已与 tar 格式及服务端校验逻辑对齐：`./` 根目录放行，`..` 穿越/绝对路径/符号链接/空文件路径仍严格拒绝
- 回归测试覆盖上述 zip 场景（修复前该用例必失败），enterprise 108 项测试全绿

## 部署

- 客户端三平台：mac DMG / win x64 Setup / linux AppImage（带 SHA256SUMS 校验）
- 服务端镜像 `ghcr.io/picoaide/picoaide-harness-server`（v2.5.7 / latest）

## 注意

- 该 zip 修复只需升级客户端（含共享技能库/市场安装链路）；服务端无需变更
- 若此前在 v2.5.5 客户端上遇到 `TAR_BAD_ARCHIVE: Unrecognized archive format`，升级到本版本即可正常安装
