# PicoAide Harness v2.2.0

发布于 2026-08-25。本版本新增 PostgreSQL 存储支持与共享技能 / 共享 Agent 预设库，能力中心聚合面板落地，企业版能力增强，并完成多智能体安全审计修复。

## 服务端存储与部署

- **SQLite / PostgreSQL 双驱动**：`-db-driver` 切换，SQLite → PostgreSQL 数据迁移工具（`cmd/migrate-sqlite-pg`）
- **Docker 化 PostgreSQL 部署**：compose 私有网段 + 固定 IP、Caddy 双证书、deploy.sh、服务端镜像发布链路
- 模型缓存命中计费（DeepSeek 缓存价）+ 高峰时段分级计价

> 注：SQLite 双后端与迁移工具已在 2026-08 随 PG-only 迁移（v2.4.1）整体下线，此处按当时发布内容记录。

## 共享技能与共享 Agent

- 共享技能库与共享 Agent 预设存储：多版本管理（name + version 复合唯一）+ 审批流（pending → approved | rejected）+ 授权
- 客户端本地技能上传与共享库更新（安装状态回显、更新到 vX）；webadmin 审批页与授权弹窗
- 企业版 Agent 分享面板：本地预设行展示、两文件 / 完整目录打包、路径穿越强制防护（真实遍历拒绝 + 测试覆盖）

## 能力中心

- 客户端能力中心聚合面板（我的 / 市场 / 组织三分区 × 类型筛选 × 状态徽章 × 多版本归并与历史展开）
- 服务端 `/api/capabilities` 聚合面 + quality 质量标记（官方 / 精选）+ 统一审批队列
- 组织分区仅展示 approved、installedVersion 可靠化、图标修正等复核修复
- 命名与信息架构决策文档落地（docs/decisions/2026-08-25-capability-hub-naming-and-ia.md）

## 安全审计与修复

- 2026-08-25 多智能体审计修复：越权、数据丢失、多版本断链、部署安全
- collectBody 超限不再 destroy socket（413 响应可送达）；auth-gate 流式读取修正；上传体限 24MB；semver 接线修正；DSH_HOME 允许 tmp 目录
- 明示 Windows / Linux 未签名并给出 SHA-256 校验指引（双语 README，含一致性哈希校验）
