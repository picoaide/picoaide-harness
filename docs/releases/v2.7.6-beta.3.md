## 一、内置技能改为普通卡片

- **现象**：打开能力中心，「平台内置技能」被渲染成**顶部置顶的一条横幅**（带标题与说明的
  独立分区，压在技能网格之上），而其它技能都是网格里的普通卡片 —— 同一个列表里两套外观。
- **现在**：
  - **未安装**的内置技能：作为普通卡片出现在「我的 → 全部 / 技能」的网格里（与其它技能
    同一套卡片外观：头像、标题、版本、描述、页脚按钮），按钮是「安装」；
  - **已安装**的内置技能：就是本机技能库里那张普通卡片（带「平台内置」来源徽章），
    **不会**再在别处重复出现；
  - 内置技能同样**参与搜索**（标题 / 名字 / 描述 / 作者 / 分类）与类型筛选；
  - 安装成功后自动刷新「我的」列表 —— 卡片立刻以"已安装"的普通技能形态出现。
- **入口没有丢**：安装入口仍然在（未安装时的那张卡片），只是不再占据置顶位置。

## 二、升级步骤

1. 从更新服务器取包（beta 渠道）：`<channel>/releases/<版本>/picoaide-server-<版本>-amd64.zip`
   与同目录 `SHA256SUMS`，先比对 sha256；
2. 备份 `.env` / 数据库 / 数据目录 → 导入镜像 → **按渠道重打镜像 tag 并写回 `.env`** →
   `docker compose up -d server`（客户端安装包随镜像刷新，员工从门户下载新客户端）；
3. 复验：容器 `healthy`、`--version` 与目标版本一致；客户端升级后打开能力中心，
   内置技能应显示为网格里的一张普通卡片。
