发布于 2026-08-27。本版本完成 PostgreSQL 全面迁移（PG-only）、技能压缩包上传与下载 / 调用统计、错误监控自动集成，并发布统一镜像包名。

## 数据库：PostgreSQL 全面迁移（PG-only）

- **彻底迁移 PostgreSQL**：删除全部 SQLite 支持（modernc 依赖、openSQLite、39 个迁移、`cmd/migrate-sqlite-pg`、compose sqlite 模式）
- **usage 原生按月分区**（PARTITION BY RANGE + 写前幂等建分区）；**日账 / 月账永久账本**（UNIQUE 约束 + UPSERT 幂等可重算，10 年数据不丢）
- 用量聚合窗口外回退永久账本（`UsageAggregateWithLedger`）；保留策略可配置（`usage.retention_months`，0 永久 / 1~120 月，webadmin Gateway 页可配）
- 0038 热路径缺失索引补全（权限 / 登录 / 审核全表扫修复）；0036 共享资源授权表级联遗漏修复（H1）
- 测试迁移至独立临时 PG 库；CI server job 增加 PostgreSQL 服务

## 技能：压缩包上传 + 下载/调用统计

- 技能商城支持**压缩包上传**（.tar.gz），归档**直接存数据库**，不再依赖 Git 仓库 / 磁盘缓存
- webadmin「上传新版」一键切换上传模式；老 Git 模式技能继续兼容
- **下载次数**：服务端自动累计每次技能包下载（GET /archive）；**调用次数**：客户端自动上报技能调用（模型 skill 工具 / 用户 /name 手势）
- 共享技能上传同样改存数据库（员工上传 → 审核 → 全员可见）

## 错误监控

- 服务端下发错误上报 DSN + 客户端 Sentry 插件自动启用；上报开关 / 等级服务端配置，按客户端真实版本区分报错
- 新增 GlitchTip 连接器（自托管错误追踪 MCP；部署地址改为用户填写）

> 注：GlitchTip 连接器已在 v2.4.5 下架——错误上报已独立自动集成，无需手动连接。

## 部署

- **部署全面 PG-only**：主 compose 即 PostgreSQL 模式；compose 拆分为完整独立文件（pg / pg-ext 各含全部服务）；`DB_MODE=sqlite|pg|pg-external` 自动叠加 override
- `deploy.sh migrate [--dry-run]`：SQLite → PostgreSQL 数据迁移（预览 → 停服 → 清空目标表 → 迁移 → 切换 .env → 重启）；备份在 pg 模式产出 pg_dump
- **镜像包名统一为 `picoaide-harness-server`** + OCI source label 关联仓库；改为 amd64 单平台（移除 arm64，QEMU 构建过慢）
- CI：Go 测试按 Asia/Shanghai 时区运行、pg-ext compose 校验补 PG_PASSWORD
