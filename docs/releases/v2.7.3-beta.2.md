## 一、连接器（MCP）令牌自动续期

- **现象**：客户端开着一两天之后，连接器（如招聘、CRM 等第三方系统）的工具调用开始持续
  报"令牌无效"，界面却仍显示"已连接"；唯一的恢复办法是重启客户端或重新走一遍授权。
- **影响**：任何使用连接器的同事都会在某一天突然用不了，且看不出原因、不知道该怎么办。
- **修复**：本版把令牌续期交给 MCP 官方授权规范实现（授权服务器元数据发现 + 刷新令牌换取
  新令牌 + 401 自动重试），并补齐三处触发时机：
  1. **调用时**：服务端返回"令牌过期"时自动换取新令牌并重试原请求，用户无感；
  2. **后台心跳**：每分钟检查一次，临近过期就提前续期；本机子进程型连接器（令牌在启动时
     注入）会在续期后自动重启该子进程，把新令牌带上；
  3. **手动**：连接器卡片上新增「刷新令牌」按钮（不会重新打开授权页）。
  同时补齐失效提示：授权确实已失效时，卡片明确显示「需要重新授权」，不再假装已连接；
  网络或服务端临时故障则保留原凭据、稍后自动重试。
- **界面新增**：连接器卡片显示「令牌有效期至 …」与「上次刷新 …」。
- **自证**：连接器包内 15 项自动化用例（含真实授权服务器交互：发现式与静态端点两类连接器、
  令牌轮换、并发只刷一次、过期自动续期与子进程重注册），整仓门禁全绿。

> 说明：本机子进程型连接器的续期路径已由自动化用例覆盖；真实第三方系统的端到端续期
> 需要在客户环境观察一次令牌自然到期（日志关键字「令牌刷新」）。

## 二、网页门户改版：下载优先

- **现象**：员工打开公司服务器地址时，首屏曾出现面向管理员的管理后台入口，普通员工点进去
  只会看到一个自己无法使用的登录页。
- **修复**：门户首屏第一动作改为「下载客户端」，管理后台入口移到页脚的低对比度文字链接
  （管理员仍可直接访问 `/admin/`）；下载按钮改为实心图标 + 「下载」文字；深色主题下自动
  切换为深色版标识；新增「客户端功能」介绍一节。运营侧无需任何配置，升级服务端镜像即可生效。

## 三、渠道客户端的数据目录（仅涉及预发布渠道）

预发布渠道（beta）客户端的数据目录与正式版保持一致（登录状态、会话、设置延续）。
如果你在本机上装过更早的 beta（v2.7.2-beta.3 ~ beta.6），那些版本曾把数据写到独立目录
`~/.picoaide-harness-beta/`；同格式世代，可把其中内容拷回 `~/.picoaide-harness/` 后继续使用。

## 升级与回滚

- **服务端**：从更新服务器取 `<渠道>/releases/2.7.3-beta.2/picoaide-server-v2.7.3-beta.2-amd64.zip`
  （内含 `image.tar`）或 GitHub Release 附件，按 `docs/deploy/AI-DEPLOY.md` 升级。
  **升级前必须备份**；不要使用 `latest` 标签，不要执行 `down -v`。本版无数据库迁移。
- **客户端**：随服务端镜像分发 —— 服务端升级后，员工从自己登录的服务器门户下载安装包即可，
  无需访问外网；已装旧版客户端的机器会收到更新提示。
- **回滚**：保留上一版镜像 tag（`v2.7.3-beta.1`），把部署配置里的镜像标签改回并重启服务端即可。

## 附件与校验

- `picoaide-server-v2.7.3-beta.2-amd64.zip`：服务端镜像压缩包（`docker load` 后使用）；
- `SHA256SUMS`：先 `sha256sum -c SHA256SUMS` 校验，再解压。
