## 一、左侧栏底部并道：面板入口收进「更多」，账户卡收成一行（客户端）

- **现象（升级前）**：左侧栏底部固定叠着 **5 行面板入口**（定时任务 / 能力中心 /
  连接器 / 浏览器 / 应用中心）、一行「设置」和一张约 140px 的账户卡，合计约 460px。
  窗口一矮，会话列表就被压到几乎看不见，滚动与切换都变难受。
- **本版怎么做**：
  - 5 个面板入口并成 **一行「更多」**：点开是向上弹出的浮层，五项按原顺序列出，
    当前打开的面板打勾；「更多」行本身会显示当前面板名（如 `更多 · 能力中心`），
    不用展开也知道自己在哪一页。
  - 账户卡收成 **一行**（头像 + 用户名 + 账户余额）：点开是向上弹出的浮层，
    内容是原来那张卡片的全部——余额 / 每月发放 / 本月已用·今日 / 刷新 / 退出登录。
    余额为 0 或取数失败时，行内数字直接标红，不用展开也能看见。
  - 底部常态从约 460px 降到约 108px，会话列表拿回约 350px；窄轨（56px）下
    对应变为 `⋯` / `⚙` / 头像三个图标。
- **交互约定**：
  - 「更多」与账户两个浮层**不会同时存在**：点其中一个会关掉另一个；`Esc` 关闭浮层
    并把焦点还给触发行。
  - 浮层向上展开，会盖住它上面的「更多」/「设置」两行——这是浮层的正常行为：
    先点浮层外任意位置（或按 `Esc`）关掉，再点那两行。
  - 「AI 在等你交还浏览器控制权」的提示仍然可见：折叠后在「更多」行上显示琥珀色圆点，
    浮层内该条目为琥珀色并把鼠标悬停文案换成可执行的指引（打开浏览器窗口点「交给 AI」）。
  - 键盘可达：`更多`/账户行都是真实按钮（`aria-haspopup` / `aria-expanded`），
    浮层内可用上下键移动、`Enter` 激活、`Esc` 关闭。
- **不影响**：会话列表、新建会话、设置面板、右侧栏、五个面板自身的内容与切换语义
  （中列整页接管、互相排斥、返回会话）均未改变。

## 二、本版同时包含 beta.3 的全部修复（与正式版同源）

- **长时间流式回复不再在 5 分钟处被掐断**（服务端）：每次 flush 前续写本次响应的
  写截止时间，空闲流不受影响；全局 5 分钟写超时仍对「完全不写」的响应生效。
- **慢链路下载客户端安装包不再被截断**（服务端）：仅对 `/updates/client/*` 静态下载
  路由按保底速率（64 KiB/s）续期，下限不倒退、上限 1 小时。
- **Office 文件预览提示不再指向不存在的开关**（客户端）：与 `zip / mp4 / odt` 一样显示
  「该格式文件暂时无法预览」，不读文件、不请求转换服务；PDF / Markdown / 代码 / 图片 /
  HTML / 文本预览不受影响。
- **代码扫描告警清零**（内部质量）：19 条告警在代码侧消除，无抑制注释，可观察行为不变。

## 已知限制（本版认账）

- **Office 文件在桌面端不能预览**：谁会遇到 → 在右栏打开 `.doc/.docx/.xls/.xlsx/.ppt/.pptx`
  的人；现象 → 只显示「该格式文件暂时无法预览」；现在怎么办 → 下载后用本地 Office 打开；计划中。
- **本版新引入**：底部两个浮层向上展开时会盖住「更多」/「设置」两行，需要先关闭浮层
  再点它们（鼠标点浮层外、或按 `Esc`）。
- 沿用仍未修的项：渠道暗色 logo 在客户端不生效（服务端门户已按系统主题切换，两端不一致）；
  能力中心每 30 秒的市场刷新可能短暂回退刚完成的安装状态（≤30 秒自愈）；详情弹层内的
  「按版本安装」结果仍显示在弹层外；内置浏览器部分低频动作文案仍为英文。
- 沿用仍未修的项：**应用窗口内的「我来操作 / 交给 AI」按钮尚未挂载** —— AI 可以驱动
  应用窗口，但人无法在该窗口内交还控制权，当前处置是关闭该应用窗口。

## 升级与回滚

- 服务端：取本渠道镜像（更新服务器附件）→ 按 `docs/deploy/AI-DEPLOY.md` 升级
  （**升级前必须备份**；不要使用 `latest`，不要 `down -v`）。
- 客户端：随服务端镜像分发；服务端升级后员工从自己登录的服务器取包，无需访问外网。
  **服务端与客户端建议同版本**：旧版客户端连到本版服务端不会新增不可用功能
  （服务端代码与 beta.3 相同），但拿不到本版的导航改动。
- 客户端版本号为 `2.8.0`，数据根仍为 `.picoaide-harness`（与上一版一致，
  登录态与历史会话延续）。
- **回滚**：本版**无新增数据库迁移** —— 保留上一版镜像 tag，改回 `SERVER_IMAGE` 后
  `docker compose up -d server` 即可；客户端重装上一版。无需恢复数据库。
  回滚后窗口底部会恢复到 5 行 + 整张账户卡的旧布局。
