# PicoAide Harness v2.6.0（2026-09-02）

本版本把管理后台的**用量统计与配额管理**从「一个 850 行的混杂大页面」重构为独立的**用量中心**（6 个子页），补齐了企业用量分析长期缺失的关键维度（部门/成员/模型/渠道余额），并为全部配额与网关敏感配置补上**字段级审计**；同时新增**月度用量报表 Webhook 推送**（P1）。

---

## 一、用量中心（6 个子页）

管理后台侧边栏「用量」→ 「用量中心」，由统一的子导航组织：

| 子页 | 内容 |
|---|---|
| 总览（默认） | 企业整体：渠道余额卡、KPI（用量/费用）、近 30 天趋势柱状图、模型 TOP10 |
| 部门用量 | 按部门聚合（**归属祖先链展开**，与预算 enforcement 同口径），含部门预算对照 |
| 成员用量 | 按成员聚合，点击进入**个人详情页**（同页含个人配额/预算情况） |
| 模型分析 | 按模型聚合（含价格列），支持按渠道（provider）维度归并 |
| 请求日志 | 请求级明细：分页 + 统计徽标 + 过滤（时间/用户/模型/类型）+ 导出 |
| 配额与预算 | 全局默认配额/部门预算管理搬家于此（原「网关设置→配额与用量」并入，不留双入口）+ 渠道配额 Adjust（add/subtract/override） |

- 全局默认配额（token/金额）设置迁入「配额与预算」页；用量保留时长保留在网关页，改名「用量策略」。
- 服务端聚合新增维度：`group=dept`（按用户当前归属链树内 SUM）、`group=provider`（models 表映射近似归并，未登记 →「(未配置渠道)」）。

## 二、新增接口

| 端点 | 说明 |
|---|---|
| `GET /api/server/admin/usage/overview` | 总览一次聚合（range/month/today/trend/top_models≤10） |
| `GET /api/server/admin/usage/requests` | 请求级日志（page/size ≤100，默认近 7 天，窗口 ≤90 天，kind 白名单 chat/embedding/search） |
| `GET /api/server/admin/providers/:id/balance` | 渠道余额（DeepSeek 原生 `/user/balance`，出示 supported/total/granted/topped_up，不落库不缓存） |

## 三、审计补全（字段级旧→新）

此前一系列敏感配置变更**零留痕**（grep 审计为空）。本版本补齐：

- 配额变更：`quota_change`（用户配额）、`dept_budget_change`（部门预算，事务前捕获旧值防止 diff 恒空）、`quota_default_change`（全局默认配额）；
- 网关配置：`gateway_config`（字段级）、`provider_create/update/delete`（密钥只记「已更换」）、`model_create/update/delete`（输入/输出/缓存/峰谷价格旧→新）；
- 报表订阅：`report_subscription_create/update/delete`。

全部进入审计哈希链，webadmin 审计页可检索。

## 四、月度用量报表订阅（P1）

`0056_report_subscriptions` 迁移 + `internal/reports` 包：

- 配置 `name/enabled/hook_url`，月度自动生成**上月闭区间**报表（明细 → 日账 → 月账口径），推送到企业 Webhook（10s 超时、幂等补跑）；
- webadmin「用量中心 → 报表订阅」页：列表/启停/新建·编辑·删除/「测试推送」。

## 五、修复与测试基建

- **能力中心 own 状态契约修复**：本地创作行的 pending/rejected 徽章与拒因还原（此前恒空）；月账重建的整月边界修正；
- **审计收敛（P3）**：版本比较/排序/计数/冲突/校验/环六项问题修复；
- **测试不依赖数据库**：Go DB 用例在无 PG 环境自动 Skip，CI 无需数据库服务即可全量验证（有 PG 时按独立临时库全量跑）；
- 补齐缺失单测（TS 10 包 + Go 4 包）。

1. **数据库迁移 `0056` 自动执行**（新建 `report_subscriptions` 表），升级前请备份；
