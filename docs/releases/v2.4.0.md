# PicoAide Harness v2.4.0

发布于 2026-08-26。本版本建立版本号与镜像发布链路，并带来桌面端多项功能改进。

## 发布链路

- **版本号统一 git tag 权威源**：新增 `scripts/version.mjs`（set / check / get），git tag 为唯一真值，一键同步 root 与 desktop 两处 package.json（semver 白名单 + 形状校验）；版本断言动态读取 package.json，根治发版时硬编码版本号失配
- **Docker 镜像自动构建发布**：推送 `v*` tag 后 CI 自动构建推送镜像（amd64 + arm64 多平台，SBOM / provenance），标签 `latest` + `vX.Y.Z` + `vX.Y`，构建参数注入版本并做实机验证

> 注：镜像包名在 v2.4.1 统一为 `ghcr.io/picoaide/picoaide-harness-server`，并收敛为 amd64 单平台。

## 桌面客户端

- **定时任务与任务看板合并**：任务看板并入定时任务（agent actions + 执行详情），执行详情支持会话跳转（在 shell 中打开执行会话）
- **浏览器操作移除全部审批弹窗**：浏览器接管操作不再逐次审批
- 客户端包体积精简 + 适配能力中心改名
- 能力中心 Tab 与筛选激活态样式修复（非激活不再显示边框 / 下划线）
- gitignore 纳入临时产物目录（temp/、.agents/skills/）
