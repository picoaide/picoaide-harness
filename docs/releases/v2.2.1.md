# PicoAide Harness v2.2.1

发布于 2026-08-25。本版本修复升级下载静默失败，并新增会话头部升级提示徽章。

## 修复

- **SHA256SUMS.txt 清单兼容 `./` 前缀**：2.2.0 起清单条目带 `./` 前缀导致客户端校验 `checksum-missing`（提示升级但下载不执行），本版本恢复裸文件名发布清单并兼容旧清单
- **下载确认后不再因重检失败静默取消**：网络波动时沿用用户已确认的版本继续下载

## 新增

- **会话头部右上角升级提示徽章**：有新版本时显示蓝色圆点与版本号，点击触发下载，下载中显示进度动画；界面内状态与系统托盘菜单同步
- 升级状态桥与手动检查触发路由（同源校验）
