发布于 2026-09-01。本版本新增桌面端 agent 执行完成/提问/审批的系统通知（点击直达会话），并隐藏设置页「插件」选项卡。

## 新增

- **桌面系统通知（agent-loop 完成/提问/审批）**：窗口在后台时，agent 任务完成、模型向你提问（ask_user_question / 计划评审）或需要权限审批时，弹出系统级原生通知——完成通知合并并发任务（3s 去抖），提问通知直接显示问题内容；点击通知自动聚焦窗口并跳转到对应会话；子代理任务不打扰（自动过滤）；前台聚焦时默认不弹（可在设置调整）
- **设置页「插件」选项卡隐藏**：桌面端与该设置页无关（与「模型」选项卡同机制），保留「侧边卡片」等功能配置入口

## 部署

- 客户端三平台：mac DMG / win x64 Setup / linux AppImage（带 SHA256SUMS 校验）
- 服务端镜像 `ghcr.io/picoaide/picoaide-harness-server`（v2.5.6 / latest）

## 注意

- 桌面通知仅在窗口最小化/后台时弹出（默认），点击通知即可回到对应会话
- 「插件」选项卡从桌面设置页移除；「侧边卡片」等其余选项卡保持不变
