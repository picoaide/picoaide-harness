# PicoAide Harness v2.6.3（2026-09）

本版本把管理后台的能力管理面与客户端对齐：**「市场 · 技能」与「能力中心」合并为单入口**（此前是两个菜单），并在技能管理页补上**归属人显示与转移**功能——配合 v2.6.2 的客户端归属权，管理端终于能直接看到「这个技能是谁的、谁能更新」，并能随时更换负责人。

---

## 一、能力中心·统一管理面 ⭐

管理后台侧边栏从两个菜单（「市场 · 技能」+「能力中心」）收敛为一个 **「能力中心」**，页内两个 Tab（与客户端「能力中心」的 IA 对齐）：

- **市场技能**：原商城管理全部功能——技能卡片网格（上架状态/归档统计/下载调用）、上架/上传新版/编辑/规范化/预览、授权、上下架；
- **组织共享**：统一审批队列（共享技能 + 共享 Agent，状态/类型筛选、通过/拒绝/删除、质量标记）+ 锁定管理。

旧 `/marketplace` 链接自动跳转到 `能力中心?tab=market`（深链兼容，不失效）。

## 二、技能归属人：显示 + 管理端指定 ⭐

- **市场技能卡片**新增「**归属 <负责人>**」行（归属人 = 首个成功发布者 / 管理员指定者，即只有归属人或管理员能发布该技能的新版本）+「**归属**」按钮：输入新负责人用户名 → 转移（服务端写 `apps.owner` + 审计 `app_owner_transfer`）；
- **组织共享审批队列**沿用 v2.6.2 的归属列与转移弹窗；
- 两处转移弹窗统一为公共组件（同一实现、同一校验、同一审计），错误与提示行为一致。
