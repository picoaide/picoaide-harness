发布于 2026-08-29。本版本完成 webadmin UI 对齐与移动端适配、登录认证方式独立配置，并下架 GlitchTip 连接器。

## Web 管理后台

- **UI 对齐 DSH 风格**：浅色 bluish 中性色、黑色 logo tile、系统字体
- **移动端适配**：侧栏抽屉 + 汉堡菜单、表格横向滚动、自适应页头

## 认证

- **登录认证方式独立配置**（local / ldap / openid / oidc），前端 Tab 式切换；强制本地 admin 恒可登录

## 连接器

- **下架 GlitchTip 连接器**（迁移 0045）：错误上报已独立自动集成，无需手动连接
- 关闭面板后重开不再自动跳授权页

## CI

- dist:win/mac 预构建改为打包脚本内执行、构建顺序 desktop 最先
- bootstrap 连接器下发断言随 GlitchTip 下架修正
