# PicoAide Harness v2.6.5（2026-09）

本版本是管理面的一次大收敛，v2.6.4 之后的全部改动：**能力中心「官方」机制 + IA 重构**、**管理后台配置入口补全（G1-G14 审计修复）**、客户端「我的」分区来源区分与市场排序评分。

---

## 一、能力中心「官方」机制与 IA 重构 ⭐

**IA 定案**：能力中心 = **技能 | 智能体 | 审批** 三个一级 Tab——技能与智能体是两个独立页面（各自市场、各自端点、各自蓝标/归属/锁定），审批是唯一交叉点（统一队列，类型筛选 技能/智能体）。

- **官方** = App 级官方属性（`apps.official`，迁移 0059 自动应用）：归属官方 → 公开市场亮**蓝色「官方」标**（管理端 + 员工端均展示）→ **普通员工不能再上传新版**（服务端 403 `OFFICIAL_LOCKED`，按类型提示「官方技能/智能体仅管理员可上传」）；
- **归属转移**扩展：管理员可把内容「转给用户」（搜索选择）或「**归属官方**」；官方↔个人双向转移；员工上传的存量 `quality=official` 自动转官方；
- **精选 featured** 保留为独立徽章（可叠加官方蓝标）；官方不再是质量值；**锁定管理**从审批页迁入技能/智能体市场页（可预先锁定名称保护官方命名）；
- **市场排序**：官方置顶 → 精选其后 → 其余；层内按综合评分 `score = 调用量×3 + 下载量` 降序（服务端计算下发，客户端直接按 score 排序）；
- **客户端「我的」分区重构**：= 已安装（市场/共享/其他安装，来源徽章区分）+ 自己制作（「自制」徽章 + 上传状态）；官方蓝标统一渲染；**官方内容更新按钮禁用**（仅管理员可更新）。

## 二、管理后台配置入口补全（G1-G14 审计修复）⭐

对全后台「有配置、无入口」缺口的系统修复：

- **G1/G2** 模型「价格」弹窗升级为「**模型编辑**」：显示名、所属上游、default_params 结构化（上下文窗口 / 最大输出 token / 并发目标），列表列更名「计费」、行内入口更名「**配置**」；
- **G3** 用户角色 UI：创建选择 super_admin/auditor/user + 行内「角色」编辑 + 列表角色徽章；
- **G4** 市场智能体管理（上架/上传/预览/授权/归属/上下架/锁定，发布走统一内核校验 preset.yml）；
- **G5** 技能编辑弹窗补描述/作者；
- **G6** 归属转移弹窗改为**用户列表可搜索下拉**（防输错用户名，当前归属标记不可选）；
- **G7** webadmin 移除遗留 auth.mode 提交；
- **G8** 配额/预算双入口收敛（用户配额唯一入口=用量中心 Adjust Quota，用户页只读+跳转定位；部门预算唯一入口=部门管理）；
- **G9** 请求日志统计徽标带 model/kind 过滤（服务端聚合同口径）；
- **G10** 部门主管改为用户搜索选择（不再受前 200 截断）；
- **G11** 上游 API Key 一律掩码展示；
- **G13** 审计保留天数管理端可配（1~3650 天，写后立即清理+审计留痕）；
- **G14** 密码最小长度可配（8~64，默认 10，全部密码校验点统一动态读取）；
- **模型输入模态**（v2.6.4 的 0058 配套 webadmin 入口）：视觉模型在模型页可选「文字+图片」，列表「图片」徽章、迁移重同步不覆盖管理员配置。

## 五、升级注意

1. **服务端升级必做**：迁移 0059 自动应用（新增 `apps.official` + 存量 `quality=official` 自动转官方）；
2. 客户端与 webadmin 需升级到 v2.6.5（官方蓝标/「我的」分区/更新禁用均为本次新增）；
3. 存量官方标记自动生效，无需管理员补操作；如需调整某内容官方属性，在能力中心→技能/智能体→「归属」中转移。
