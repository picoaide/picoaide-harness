刷新链路（数据流）

每次 agent loop 完成后自动刷新：
node 侧（dsh-enterprise）ctx.on('agent/status', …) 收到 status === 'idle'（running→idle 转变 = 本轮 loop 结束） → 单飞行（in-flight 去重 + 300ms 防抖）拉取 {serverURL}/api/auth/usage（Bearer token） → 写入 node 内存缓存 {data, fetchedAt}，并更新本地路由 /api/pico/usage

client 侧（React 组件）：挂载时拉取 + 每 10s 轮询本地路由（零网络、零成本）→ 余额实时更新；fetchedAt 超过 60s 显示「—」防误导

其他刷新触发：登录成功 / 会话恢复时立即拉取一次；手动「↻ 刷新」按钮；token 失效（401）→ 清会话回登录页（复用现有 auth-expired 逻辑）

边界状态

✓ 正常显示余额 + 进度 + 用户名
⚠ 无配额（不限）显示本月/今日消耗，无进度条
⚠ 低余额 ≤20%进度条橙色 + 「余额不足」文字
✗ 拉取失败显示「—」+ 保留上次值，不闪错误
✗ 401清会话 → 自动回登录页（现有 tripwire）
